AEROSCAPE WEBSITE

Open index.html in a web browser to preview the site.
To publish for free, upload the entire aeroscape-website folder to Netlify Drop (https://app.netlify.com/drop) or deploy through GitHub Pages.

All gallery images are included in assets/. Website uses Google Fonts when online, with system font fallback.
Instagram links go to https://www.instagram.com/aeroscape_43/.
This is a static portfolio; no backend or hosting account is included.
